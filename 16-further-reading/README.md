## How new books will be added

When we read the next book:

1. Keep DDIA chapter folders stable (do not renumber 1–14).
2. Either extend section 15 (if it is a *design problem*) or add a
   subfolder here (if it is a *new lens* on the same theory).
3. Cross-link back to the DDIA chapter that already taught the idea,
   the same way these notes link to Joshi and Kafka.

Until then, the reading order is: **DDIA 1 → 14**, then come back.
